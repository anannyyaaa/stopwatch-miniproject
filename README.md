# ⏱️ Stylish Stopwatch Web App

A modern and responsive **Stopwatch Web Application** built using **HTML, CSS, JavaScript, and React (via CDN)**. This project focuses on combining clean UI design with core React concepts like state management and timers.

Link : https://anannyyaaa.github.io/stopwatch-miniproject/
---


## 🚀 Features

* ⏯️ Start, Stop, and Reset functionality
* ⏱️ Real-time stopwatch (HH:MM:SS format)
* 🎨 Modern UI with **glassmorphism design**
* 🌈 Gradient buttons with smooth animations
* ⚡ Built using React without any setup (CDN-based)

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling (Glassmorphism + Gradients)
* **JavaScript (ES6)** – Logic
* **React (CDN)** – UI & State Management

---

## 🧠 Key Concepts Used

* React `useState` for managing time and running state
* React `useRef` for storing interval reference
* `setInterval` & `clearInterval` for timer functionality
* Time formatting logic (seconds → HH:MM:SS)
* Responsive and modern UI design principles

---

## ⚠️ Limitations

* Uses React via CDN (not suitable for production apps)
* No component-based file structure
* No advanced features like lap tracking or milliseconds
